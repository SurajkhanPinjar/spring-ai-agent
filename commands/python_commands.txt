🐍 Python Command Cheat Sheet

A handy reference for Python developers — from setup to everyday scripting and debugging.
Ideal for beginners and pros who want quick terminal + code-level commands.

⸻

🚀 Setup & Installation

# Check Python version
python --version
python3 --version

# Check where Python is installed
which python       # macOS/Linux
where python        # Windows


⸻

⚙️ Running Python Scripts

python file.py       # Run Python script
python3 file.py

Interactive Shell

python               # Start Python REPL
exit()               # Quit REPL


⸻

🧰 Package Management (pip)

pip --version                     # Check pip version
pip install <package>             # Install a package
pip uninstall <package>           # Remove a package
pip list                          # Show installed packages
pip show <package>                # Show package details
pip freeze > requirements.txt     # Save dependencies
pip install -r requirements.txt   # Install from file


⸻

🧩 Virtual Environment

# Create virtual environment
python -m venv venv

# Activate environment
source venv/bin/activate          # macOS/Linux
venv\Scripts\activate             # Windows

# Deactivate
deactivate

🗂️ File Operations (In Python)

import os

os.getcwd()             # Get current directory
os.listdir()            # List all files
os.mkdir("test_dir")    # Create directory
os.remove("file.txt")   # Delete file

# Reading a file
with open("data.txt", "r") as f:
    print(f.read())

# Writing to a file
with open("data.txt", "w") as f:
    f.write("Hello Python!")

📊 Data Structures (In Python)

# List
nums = [1, 2, 3]
nums.append(4)
nums.remove(2)
nums.sort()

# Dictionary
user = {"name": "Suraj", "age": 25}
user.keys()
user.values()

# Set
unique = set([1, 2, 2, 3])
